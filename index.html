คำถามที่พบบ่อย

เปิดแล้ว Windows ขึ้น "Windows protected your PC"

เป็นเพราะไฟล์ยังไม่มีลายเซ็นดิจิทัล กด More info → Run anyway ได้เลย โปรแกรมไม่แตะไฟล์เกมและคืนค่าได้ทุกข้อ

แอนติไวรัสเตือน

โปรแกรมปรับเครื่องทุกตัวแก้ค่าของ Windows จึงอาจโดนแอนติไวรัสบางตัวเข้าใจผิด เราสแกนไฟล์ทุกเวอร์ชันก่อนปล่อย ตัวหลักอย่าง Windows Defender, Kaspersky, ESET, Avast ไม่จับ ถ้าเจอเตือนแจ้งแอดมินในดิสได้

เปิดโปรแกรมค้างไว้ตอนเล่น กิน FPS ไหม

ตอนอยู่ในเกม โปรแกรมหยุดแอนิเมชันและเสียงทั้งหมดเอง ค่าที่ปรับแล้วอยู่ใน Windows จะปิดโปรแกรมก็ได้ ยกเว้นฟีเจอร์ที่ทำงานระหว่างเล่น เช่น ล้างแรมอัตโนมัติ

จะได้ FPS เพิ่มเท่าไหร่

แต่ละเครื่องไม่เท่ากัน เราจึงไม่โฆษณาตัวเลข ใช้ภารกิจวัดผลในโปรแกรมวัดบนเครื่องคุณเองได้ทั้งก่อนและหลัง

ใช้ ReShade ยังไง

ปิดเกม → เครื่องมือ → ReShade → กด พร้อมใช้พรีเซ็ต โปรแกรมติดตั้งและใส่พรีเซ็ตให้ครบ เข้าเกมภาพเปลี่ยนเอง กด Home เปิดเมนู

อยากกลับเป็นแบบเดิม

กดคืนค่าในหน้าปรับแต่งได้ทุกข้อ โปรแกรมเก็บค่าเดิมไว้ทุกครั้ง
