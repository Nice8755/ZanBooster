        วิธีใช้ Zan Booster

        1ครั้งแรกที่ใช้ ทำครั้งเดียว
        1. คลิกขวาที่ ZanBooster.exe → Run as administrator โปรแกรมต้องใช้สิทธิ์นี้ถึงจะปรับเครื่องได้
        2. ไปหน้า ตรวจเครื่อง ดูว่าเครื่องมีจุดไหนต้องแก้
        3. ไปหน้า ปรับแต่ง เลือกค่าที่อยากปรับ แล้วกดใช้ โปรแกรมเก็บค่าเดิมไว้ทุกครั้ง อยากคืนค่ากด "คืนค่า" ได้ตลอด
        4. ไปหน้า กราฟิกเกม เลือกแบบที่ต้องการ
          ลื่นสุดต่ำสุดทุกอย่าง เน้น FPSสมดุลคำนวณจากสเปคเครื่องสวยสูงสุดเท่าที่เครื่องรับไหว
        5. รีสตาร์ทเครื่อง 1 ครั้ง
        2ทุกครั้งที่จะเล่น
        1. เปิด Zan Booster → หน้าหลัก
        2. ถ้ายังไม่มีเซิร์ฟในรายการ ให้ใส่ IP:Port หรือโค้ด cfx.re/join/xxxxxx แล้วกด เพิ่มเซิร์ฟ รายการจะโชว์ชื่อเซิร์ฟ ธงประเทศ ปิง และจำนวนคนแบบสด
        3. กด เข้า ที่เซิร์ฟที่ต้องการ ปุ่มจะบอกว่าทำอะไรอยู่ (เปิดเกม → รอหน้าเมนู → ส่ง IP)
          ถ้าเปิด FiveM ค้างไว้ที่หน้าเมนูก่อน จะเข้าได้เลย ไม่ต้องรีเกม
        4. พอเข้าเกมแล้ว ปิดหน้าโปรแกรมได้เลย โหมดเล่นเกมยังทำงานต่อจนออกเกม
        ถ้าติ๊ก "เตรียมเครื่องก่อนเข้า" ไว้ โปรแกรมจะปิดโปรแกรมที่กินเครื่องและล้างแรมให้ก่อนเข้าเซิร์ฟ
        3หน้าอื่น ๆ
        • บูสต์กดทีเดียว เครื่องเร็วขึ้นทันทีแบบชั่วคราว
        • วัดปิงดูปิงกับอาการเน็ตกระตุก
        • เครื่องมือแท็บ เครื่องมือ: ล้างแคช FiveM, ล้างไฟล์ขยะ, ดัน Priority, เตรียมเครื่องก่อนเล่น
          แท็บ โหมดเล่นเกม: เปิด/ปิดแต่ละข้อได้ ดูว่าอะไรเป็นตัวถ่วง และล้างไฟล์เก่าในแคชเซิร์ฟ (ต้องปิด FiveM ก่อน)
          แท็บ คำแนะนำการตั้งค่า: ทิปปรับในเกมและการ์ดจอ
        • บันทึกดูว่าโปรแกรมทำอะไรไปบ้าง ถ้ามีปัญหาส่งภาพหน้านี้มาให้ดู
        • เกี่ยวกับเช็กอัปเดต และส่งรายงานปัญหา
